# Contributing

Bug reports, test results and findings are very welcome. The easiest way is **Report Issue** in OverPass: it
collects the log, your Mac's details and the game's settings for you. **Help › Report Issue…** is for a problem with
OverPass itself and **Help › Request Feature…** for an idea. Or open an issue with:

- what you saw;
- how to reproduce it;
- your Mac, your macOS version and your OverPass version.

Game profiles are welcome too: a profile that makes a game work (the `.ini` from the profile editor's Export,
see [the profile format](profiles/README.md)), with what you tested.

Pull requests must be written by people. We don't accept pull requests generated by AI agents or language
models, or opened in bulk. Using AI for your own research is fine: share what you found in an issue instead.

Keep pull requests small and about one thing. Say what was wrong and how you tested the fix, and follow the
existing code style.

Changes to Wine belong in [overpass-wine](https://github.com/McKack/overpass-wine), to Direct3D in
[overpass-runtime](https://github.com/McKack/overpass-runtime), and to component versions in
[overpass-components](https://github.com/McKack/overpass-components). Changes that aren't specific to OverPass
belong upstream, following that project's contribution rules.
